- HTTP 处理器统一继承 `BaseHandler`，并通过 `send`/`json` 方法设置 UTF-8 Content-Type 并写响应体，错误路径返回 `{"error": ...}` JSON。
- 多表并发访问以 `Table` 对象自身为锁（`synchronized (t)`），同表串行、不同表并行，避免在请求线程中直接持有全局锁。
- 持久化写入一律先写 `<id>.json.tmp` 再 `Files.move` 原子替换，失败回退非原子覆盖，保证崩溃不损坏旧快照。
- 决策后端通过 `SwitchableBackend` 的 `volatile` 委托字段暴露给 `SemQuestTree`，热切换仅替换引用而不重建树实例。
- 配置文件键值通过 `Config.get(key, dft)` 读取，优先级固定为 JVM 系统属性 `-Dsemquest.KEY` > properties 文件 > 代码默认值。
- LLM 提示词模板集中在 `SemQuestTree.Prompts`，通过 `prompt.noul.*` / `prompt.choice.*` 等 key 注入占位符（`{name}`、`{yes}`、`{node}`），空值回内置默认。
