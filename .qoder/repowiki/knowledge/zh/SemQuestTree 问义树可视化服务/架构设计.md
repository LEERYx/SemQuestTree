单包 `org.example` 扁平结构，按职责分为四层：
- 运行时入口与 HTTP 层：`SemQuestServer` 基于 JDK 内置 `com.sun.net.httpserver.HttpServer` 暴露 REST API（`/api/tables`、`/api/t/<id>/<action>`、`/api/models`、`/api/model`），内部用 `BaseHandler` + 若干 `static final class XxxHandler` 实现路由分发；`viz.html` 作为静态页面由 `StaticHandler` 磁盘实时读取。
- 核心数据模型：`SemQuestTree` 维护 `SemNode` 树（每层兜底 `_OTHER` 叶）、`Doc` 指针集、LFU 查询缓存与 `Prompts` 提示词模板；`add` 与 `quest` 走同一套下行逻辑，仅规则文本不同。
- 决策后端抽象：`DecisionBackend` 接口定义 `noul` / `choice` 两种判定方言，`SwitchableBackend` 以 `volatile` 引用包装实现热切换 provider/model 而不重建树；具体实现为 `JevBackend`、`OpenRouterBackend`、`BailianBackend`、`MockBackend`。
- 配置与工具：`Config` 提供带 JVM 系统属性优先级的 properties 热载（2s mtime 轮询）；`Json`、`Http`、`NoulSpec`、`NoulReply` 为共享工具；`Demo` 提供种子语料与 CLI。
持久化采用 `tables/<id>.json`（schema + docs + grown/edits 回放日志），启动时先回放结构再挂正文，零模型调用恢复；旧版 `driver-intent-schema.json` + `tree-data.json` 自动迁移为 demo 表「司机意图」。
