# 判据质量与树形态调节 · 大改设计

- 状态：设计共识（未实现）
- 来源：2026-11-18/19 两日讨论纪要，锚定实证表 `t-mwlqeq1m`（96 条落位，38 个一层分支）
- 配套机制文档：docFilter 出检过滤见 `docs/API.md` quest 段；自生长见 `docs/SELF-GROWING.zh-CN.md`

## 1. 背景与病灶重定性

96 条落位表暴露五类现象：弱相关内容误入分支（「用户30岁了」落「情感偏好：择偶标准，外貌喜好，恋爱倾向」）、近义分支（职业身份/职业状态）、复合问句检索感知差、疑似失败落位、ROOT_OTHER 悬空指针（9 条，指向已不存在的兜底叶）。

定性修正：

- 门控双时代混染：0.7 门控时代长树（兜底频繁触发生长，长出近义窄门分支），0.2 门控时代灌数（弱相关轻松过门，误落污染）。同一张表是同一个旋钮两个极端的病理样本。
- **病灶重心**：节点间结构关系（包含/相离/相交）基本全部合法，病集中在**判据文本的域定义质量**——全表 39 条判据，命题式占比 0%（全部为名词短语列举「标签云」），判定模型被迫对标签云即兴脑补命题，弱相关糊分由此而来。
- 因此实施顺序上**判据质量先行，结构机制（维度门控/升降维）在后**——两者都是在判据语义空间里做几何操作，基准不准则操作失真。

## 2. 设计总览

```
地基（判据层）                          结构（树形态层）
├─ 判据宪法（三条硬约束）               ├─ 维度门控 —— 维度分配器（纵向）
├─ add/search 双模板投影                    ├─ 高分落选信号 —— 防相近分支（横向）
├─ 节点关系分类学（相交合法化）         ├─ 水位延伸 —— 纵向生长（已有）
└─ 观测体系（体检报告）                 └─ 升降维重构 —— 密度调节器（横向）
```

维度门控决定「什么粒度的节点允许长在哪层」，升降维决定「每层塞多少个节点」——正交两轴。

## 3. 判据设计

### 3.1 add/search 双模板投影（单份属性解释）

判据本体只有一份：**属性解释**——对节点语义域的抽象、连贯描述（不是名词标签列举，也不是预设主语的完整命题）。语域差异由两个固定模板承担：

- add 判据：`这条内容是否和〔属性解释〕有关`——内容 vs 域，正常判定姿态
- search 判据：`用户输入的内容是否和这个抽象有关，哪怕一丝关联〔属性解释〕`——查询 vs 域，卑微姿态（沾边即算）

- 判据字段命名为 `add` 与 `search`；no 判据不再单独生成——`no = 并非〔属性解释〕`，由模板推导。
- **域覆盖不变量由模板措辞结构保证**（「有关」vs「哪怕一丝关联」），不依赖生成器维护多份文本的一致性。
- 现有 `ruleAdd`/`ruleSearch` 双模板即此设计雏形，本次将其措辞标准化，属性解释本身的质量写进宪法。
- 生成成本进一步降低：每次生长只产出一份属性解释。

### 3.2 判据宪法

**三条硬约束**（违反即不合格）：

1. **属性解释性**：判据本体是对语义域的抽象属性解释——连贯的域描述句；禁止逗号列举式名词短语（配真实病灶做负例：「择偶标准，外貌喜好，恋爱倾向」坏 → 「用户在择偶条件、伴侣外形偏好与恋爱倾向方面的特征与表达」好）；禁止照抄触发样本措辞（防过拟合）。
2. **边界可判**：属性解释划出的域边界可判定，理性读者在 add/search 模板拼装下读完内容能明确答 yes/no，无需语义联想。
3. **维度递进**：子节点维度 > 父节点维度（维度为节点属性，验收硬检查，见 5.1）。

**软倾向**（推荐非强制）：

- 维度梯度：浅层偏宽域、深层偏窄域——作为统计倾向存在；层内允许平铺混杂（见 5.5），粒度由节点维度显式表达而非层深代理。
- 轴一致：兄弟沿同一属性轴切分父域是画清边界的省力路径，但允许正交切分，以「边界可判」为最终标准。

**add 模板附加**：正常判定姿态。
**search 模板附加**：卑微原则（见 3.3），固化在模板固定措辞中。
**共同条款**：重合度小（允许相交，交集要窄）、子域 ⊆ 父域。

### 3.3 search 判据的卑微原则

检索要找蛛丝马迹，search 模板措辞低姿态：「查询是否与节点方向**有一点关系**」——沾边即 yes，容错高，宁可宽进不可错过。

- **与维度门控配合**：每层卑微一点、层层收敛——首层卑微到方向沾边全过（配低门控），逐层具体化，多层低姿态累乘自然收敛到具体分支。
- **与 docFilter 配合**：宽进细筛漏斗——路由判据卑微（宽进）→ docFilter 严格细筛（doc 原文 vs 查询）→ 排序。**宽容放在不可挽回的上游（路由层错过无法挽回），严格放在可挽回的下游（滤多只是漏斗损耗）**。

### 3.4 生成语境包

生成 add/search 判据时生成器的输入（缺一项即对应条款无从谈起）：

| # | 输入 | 保障的条款 |
|---|---|---|
| 1 | 父节点判据（属性解释）及其维度分 | 子域 ⊆ 父域、维度递进 |
| 2 | 兄弟节点判据（属性解释）及维度分 | 重合度小、边界可判 |
| 3 | 触发样本 | 域归纳、防过拟合 |
| 4 | 高分落选信号（见 5.2） | 避让相近语义 |
| 5 | 层容量（当前选项数/剩余空间） | 成枝 or 平铺的粒度决策 |
| 6 | 父节点维度 + 目标维度区间 | 属性解释的粗糙度落在父域内且更细 |
| 7 | 输出契约 | 单份属性解释（域描述句） |

## 4. 节点语义关系分类学

| 关系 | 集合表达 | 存在位置 | 约束 |
|---|---|---|---|
| 包含 | B ⊂ A | 跨层（父子） | 子域 ⊆ 父域 |
| 相离 | A ∩ B = ∅ | 同层兄弟 | 理想态 |
| 相交 | A ∩ B ≠ ∅，互不包含 | 同层兄弟 | 苛刻：同父 + 交集 ⊆ 父域 + 重合度小 |

**多叶落位合法化**：doc 同时落两个相交兄弟（如职业身份+职业状态）= doc 两面兼容，合法，冗余路由甚至利召回。

- 双叶分两类：**相交双叶**（真兼容，合法）vs **模糊双叶**（判据边界糊导致的误判，病）。区分手段：docFilter 分数——双叶 doc 在两叶的 docFilter 都高分 = 真兼容；一边高一边压线 = 疑似模糊。
- **合并机制收缩**：仅治理「近乎全等」（A∩B ≈ A 或 ≈ B，一个几乎吞掉另一个）；合法相交保留，不做合并。

## 5. 树形态四级调节系统

### 5.1 节点维度与维度门控（维度分配器）

- **维度是节点属性，不是深度函数**：每个节点带维度分（0~5，比 0-1 打分容错更高），由决策模型在生长验收时打分。打分提示词必须给出维度定义（语义粗糙度：0 = 极宽泛领域词，5 = 原子事件级细节）。层内粒度混杂（5.5）下深度不再代表粒度，显式打分取代深度代理。
- **维度门控**：判定门控 = 维度的函数——维度高（细判据）门控严，维度低（宽判据）门控松（映射如 gate = 0.2 + dimension × 0.1，具体曲线待标定）。取代原「深度公式」设计。
- **维度递进规则**：子节点维度 > 父节点维度——写进生成提示词（语境包 #6 给出父维度与目标区间），并在验收时硬检查，不满足打回重写。
- **验收双测**：生长验收除触发样本原文落位测试（重判 P 过门）外，新增维度打分环节。
- **盲测实验结论（2026-11-19 已验证，dim-experiment.py）**：生成模型（qwen3.7-flash，生产同款打分提示词）对 16 条样本（6 条同域梯度序列 + 10 条真实树判据）盲测 2 轮——**条件通过**：
  - 同域梯度序列严格单调不减 [0.5, 1.0, 1.0, 1.5, 3.5, 3.5]，零违例（核心验收项）；
  - Spearman 秩相关 0.610（n=16），轮间一致率 16/16（|Δ|≤1，打分稳定非噪声）；
  - 已知局限：跨域打分区间压缩（预标 0~3 全挤在 0.5~2.0，违例对 32/97 多为并列而非逆序）；打分器对判据形态敏感（名词列举式存量判据被打低分，属性解释体得分合理）。
  - **维度属性可信；维度门控标定如下（按打分段而非预标段）**：`gate_add(dim) = 0.35 + 0.06 × dim`（dim0=0.35 松 → dim5=0.65 严）、`gate_quest(dim) = gate_add(dim) − 0.2`（卑微姿态恒低 0.2）。当前静态 addGate=0.5/questGate=0.3 ≈ dim 2.5 单值，与存量树 dim 1~2 现状匹配。
  - **启用条件**：动态门控须待存量换轨（判据改写属性解释体 + 维度补评）完成后开启——存量树 dim 全为 0，动态曲线会退化为 dim0 档并漂移落位基线（见 §9 门控锁定策略）。
- **门控分离**：`addGate`（归属判定）与 `questGate`（相关性判定）分开，两者都是维度的函数但曲线不同（search 判据整体卑微，其门控曲线更宽松）。这是全部机制里优先级最高、改动最小的一条。
- 效果：弱相关内容被宽判据大类吸收、生长发生在「大类内部细分位置」而不是第一层被弱相关逼着分裂；窄门分支不再诞生；维度成为树的固有属性后 add/quest 基线不再漂移。

### 5.2 高分落选信号（生长防相近）

add 判定的 noul 批量响应里带着触发内容对**所有**分支的 P 值，当前只消费「过门控」布尔，分数被丢弃。将「未过门控但相对较高」的分支名+分数捡出，注入生长生成器输入——生成器拿到的不是抽象 siblings 清单，而是「触发内容在现有分支上的真实判分分布」，直接避让相近语义。**零额外调用**。

### 5.3 水位延伸（纵向生长，已有）

叶 doc 数过水位 → 延伸子节点。**水位初值 20**：叶存量达 20 即延伸，配合 maxBranches=20 使每层判定请求不超过 20 题（与 docFilter batch=20 同规格，注意力摊薄可控）。容量账：每层 20 分支 × 叶水位 20，三层 8000 叶 ≈ 16 万 doc，四层 ≈ 320 万，树可由升降维自由调深。初值可标定调整。

### 5.4 升降维重构（密度调节器）

生长时机维持「兜底即生长」不变，首条片面结构交给升降维修正，不做攒批延迟——不存在「不片面的条数」，只存在「可修正的结构」。

- **上提**（某层占满率极低而某子节点扇出爆炸）：溶解粗粒度节点、子节点顶上来。判据原样带走，兄弟语义距离反而变远。**零模型调用**。
- **下沉**（某层逼近占满目标且兜底堆积）：语义归组下沉腾位。子判据原样保留，仅生成新父概括判据（1 次生成调用：输入兄弟判据 → K 组 + 每组概括）。存量落位叶全部原样，检索仅多一跳。
- **两个不变量**：判据不动（索引跟判据走，存量零重判）；**维度随节点迁移**（下沉子树带走自己的维度分，门控由维度函数重算，判定基线不漂移）。上提是安全方向（维度域内吸收变宽），下沉按原维度走。
- **粒度决策前置**：生长生成器输入带层容量（语境包 #5），生成时即做「成枝 or 平铺」决策——空间紧则新内容不独占分支，细分直接平铺或并入相邻宽判据。升降维保留给分布漂移后的修正（如后期生活类内容涌入重排编程平铺层），触发频率因此大幅降低。
- **并发边界**：单子树内的上提/下沉可并发（锁粒度从 Table 级细化到子树级）；跨子树归组聚类是全局语义操作，须串行。
- **占满率初值 20**：maxBranches 255 → **20**——每层判定请求不超过 20 题，判定质量稳；容量由树深补偿（见 5.3 容量账）。触发加迟滞（重构后 N 条 add 内不再触发），防结构抖动与缓存反复失效。

### 5.5 层内粒度混杂（有意设计）

兄弟节点**不要求**语义同维度：「编程」下可同时有「游戏编程」（宽）与「java」「spring」「数据库慢sql」（细）——noul 每选项独立判分互不污染，粒度混杂在判定上无代价，铺满优先于整齐。树是路由表不是图书馆目录。代价与约束：宽窄混杂下「域不相交」升级为「域不嵌套模糊」——粒度差导致的冗余双叶允许，边界模糊双叶不允许（见 4）。

## 6. 观测体系（判据体检报告）

**零成本指标（纯查现有快照，可每日跑）**：

| 指标 | 度量 | 对应条款 |
|---|---|---|
| 属性解释性分数 | 符合属性解释体（连贯域描述句）的判据占比（现状 0%，全为标签云） | 宪法 #1 |
| 双叶拆分 | 相交双叶（docFilter 双高）vs 模糊双叶（一边压线） | 关系分类学 |
| 兜底堆积率 | 各层 X_OTHER 存量占比 | 组内完备 |
| 窄门率 | 存量 <3 的分支占比 | 维度匹配 |
| 悬空指针数 | doc.leaves 指向不存在叶（现状 9 条） | 一致性 |

**低成本指标**：区分性试判（新判据上岗前拿高分落选分支的 1~2 条存量反测，应判 no，判 yes 当场打回重写）；邻域黏连度（存量 doc 在兄弟判据下的 P 值分布）。

**检索端对账**：DOC_FILTER 轨迹（已上线）将路由判定与 doc 相关性判定分开打分——quest 命中叶后 docFilter 大量滤除 = 路由判据语义错位的病灶定位。

报告形态：每表一份（属性解释性分布、Top 相交对、窄门清单、兜底堆积排行），挂 viz。

## 7. 存量治理：判据换轨

对「属性解释性分数低 + 模糊双叶高」的分支，用新宪法改写属性解释（输入：旧判据 + 分支存量样本 → 输出新属性解释，1 次生成/分支）+ 存量重判分流（1 次打包判定/分支）。38 个分支 ≈ 80 次以内调用，一次性成本，观测指标定优先级，不必全改。单份属性解释使换轨成本比双文本方案再降一半。

## 8. 实施顺序

1. **维度打分盲测实验**（决策模型对异粒度判据的维度打分单调性验证，1~2 次调用）——维度属性可信度的前置关卡
2. **宪法 + growth-prompt/growth-extend-prompt 重写**（纯提示词文件，零代码）——属性解释 + 双模板措辞标准化，只影响新判据
3. **门控分离 addGate/questGate + 悬空一致性校验工具**（最小代码量，收益直接）
4. **体检报告**（观测脚本 + viz 呈现）——量化存量病灶、建新判据质量基线
5. **存量换轨**（观测驱动，改写属性解释 + 重判）
6. **维度门控 + 高分落选信号**（维度门控映射曲线用换轨后的打分分布标定）
7. **升降维**（生成时粒度决策 + 事后重构）

## 9. 风险与待定项

- **维度打分可靠性**：盲测若显示决策模型维度打分不单调（细判据得分低于宽判据），维度属性方案降级——退回「门控按层深 + 层内混杂容忍」或尝试在打分提示词中加入判据对照组再验。
- **维度门控映射标定**：gate = f(dimension) 曲线（add/search 两条）在换轨完成、打分分布稳定后统一标定；换轨前旧数据不适用新曲线。
- **search 端试判冷启动**：无「典型查询」可用，初期靠生成器自检（输出两个示例查询自查）+ 上线后 quest 命中率观测补位。
- **choice 方言跟进**：choice 判据与 X_OTHER 兜底选项、「以上都不符合」选项需接入属性解释 + 双模板体系，遗漏会留下死角。
- **双叶基线重校准**：卑微模板落地后双叶系统性变多，多叶率旧基线作废；「重合度小」暂取定性观测（只抓模糊双叶），数值基线待数据积累后定。
- **门控锁定策略**：维度为节点属性、随节点迁移；UI 是否保留逐表覆盖待定（保留则存在人为基线漂移风险，需在 UI 上标注「门控变更后存量分布与新基线脱节」）。
- **复合问句**：卑微 search 模板 + 属性解释路由后部分缓解；查询拆解（多意图子查询分别 quest 再合并）作为可选增强，按评测中复合问句占比决定是否实施。
